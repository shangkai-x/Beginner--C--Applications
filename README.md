# Beginner--CS--Applications
Beginner projects on C# to learn the foundation.

## 🚀 Features
* **Calculator:** Performs basic math (addition, subtraction, multiplication and division)
* **Number Guessing Game:** Compares user input against a randomly generated number.
* **Turn base combat Game:** Allows the user to engage in a turn base game.
* **rock paper scissor:** A simple rock paper scissor game.
* **Shape area calculator:** Allows the user to calculate the area of a basic rectangle or circle.
* **Dice Game:** Allows the user to play a dice game against an AI bots.
